# 个人财务管理与可视化看板

一个面向个人和家庭日常使用的财务管理产品。它通过低负担记账、统一账户视图、预算控制和趋势分析，帮助用户持续回答三个问题：钱在哪里、钱花到了哪里、下一步应该如何调整。

当前仓库包含可直接运行和提交的课程实训版本。数据默认保存在当前浏览器的 `localStorage` 中，不会上传到服务器。

## 快速开始

推荐直接双击 `run.bat` 启动提交包；开发调试需要 Node.js 20 或更高版本，在项目根目录运行：

```powershell
npm start
```

然后打开 <http://127.0.0.1:4173>。首次进入会载入一组演示数据；新增交易、账户和预算后会自动持久化。

当前可用能力：

- 查看净资产、本月收支、结余率和累计资金轨迹；
- 新增支出、收入和账户间转账，余额自动联动；
- 按月份、类型和关键词查询交易，编辑或删除错误记录；
- 添加资产或负债账户，统一查看实时余额；
- 设置分类月度预算，查看正常、提醒和超支状态；
- 导入标准 CSV、识别疑似重复交易、查看批次并整批撤销；
- 创建储蓄或还债目标，持续更新进度与剩余金额；
- 查看最近六个月现金流、分类支出结构和本月分析结论；
- 一键隐藏全部金额，支持桌面端和移动端布局。

## 产品方向

- 以“看清财务状态并采取行动”为核心，不把产品做成单纯的流水账本。
- 先覆盖手动记账与标准化账单导入，再根据真实需求评估金融账户自动同步。
- 用净资产、现金流、预算执行和财务目标构成首页核心视图。
- 默认保护隐私，敏感信息最小化采集，导入和删除过程可预览、可撤销、可追踪。
- 当前课程版本服务单个用户，家庭协作、投资交易和专业财务建议不属于本次提交范围。

## 课程提交版主要功能

1. 资产、负债与账户管理
2. 收入、支出和转账记录
3. 分类、标签与批量整理
4. 月度预算及超支预警
5. 净资产、现金流和支出结构看板
6. 储蓄与还债目标跟踪
7. CSV/Excel 账单导入与重复数据识别
8. 数据导出、备份与彻底删除

## 文档验证

运行全部自动化测试与文档检查：

```powershell
npm run validate
```

真实浏览器冒烟测试需要 Python Playwright。保持 `npm start` 运行，并在另一个终端执行：

```powershell
py -3 tests/browser-smoke.py
```

浏览器测试会验证交易新增与编辑、筛选、导入撤销、预算、目标和响应式布局。测试生成的截图保存在 `tests/artifacts/`。

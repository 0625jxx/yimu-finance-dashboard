# 个人财务管理与可视化看板 · 提交说明

## 提交信息

五位小组成员及学号已经写入 Word、PDF 和答辩 PPT，并按 20% 均等贡献列出建议分工。班级与指导教师由生成环境变量写入，生成器会拒绝缺失信息，避免带占位符提交；如实际分工比例不同，请同步调整报告中的“小组分工”表。

## 交付内容

- `yimu-finance-dashboard.jar`：Java 17 可执行程序；
- `yimu-finance-dashboard.db`：包含完整关系表结构的 SQLite 数据库；
- `个人财务管理与可视化看板-综合实训设计报告.docx`：完整实训报告；
- `个人财务管理与可视化看板-答辩演示.pptx`：11 页答辩演示；
- `个人财务管理与可视化看板-综合实训设计报告.pdf`：便于预览和打印的报告 PDF；
- `SHA256SUMS.txt`：交付文件校验值。

## 演示运行

1. 确认电脑已安装 Java 17 或更高版本；
2. 在项目根目录双击 `run.bat`；
3. 浏览器打开 <http://127.0.0.1:4173>；
4. 建议按“概览 → 新增交易 → 预算 → 报表 → 导出数据”的顺序演示；
5. 演示结束后关闭命令行窗口即可停止程序。

## 测试命令

```powershell
npm run validate
npm run test:browser
mvn test
mvn -o clean package
```

通过 JAR 启动时，财务数据经本机 REST API 保存到 `data\yimu-finance-dashboard.db`；提交目录同时包含一份已建表的数据库，建表 SQL 位于根目录 `database\schema.sql`。使用 Node 开发服务器时才会回退到当前浏览器的 `localStorage`。首次进入自动加载演示数据；如需恢复干净环境，可点击侧栏底部“清除全部数据”。

## 数据库验证

数据库包含 `accounts`、`transactions`、`budgets`、`goals`、`import_batches` 和 `app_meta` 六张表。`mvn test` 会使用临时数据库验证建表、外键、事务读写、HTTP API 和跨服务重启恢复。

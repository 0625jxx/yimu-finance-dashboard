# 个人财务管理与可视化看板 · 提交说明

## 提交前只需完成一件事

请在 Word 报告封面、报告“小组分工”以及答辩 PPT 首页中，把所有 `【请填写】` 占位符替换为真实的姓名、学号、班级和指导教师。

## 交付内容

- `yimu-finance-dashboard.jar`：Java 17 可执行程序；
- `个人财务管理与可视化看板-综合实训设计报告.docx`：完整实训报告；
- `个人财务管理与可视化看板-答辩演示.pptx`：11 页答辩演示；
- `个人财务管理与可视化看板-综合实训设计报告.pdf`：便于预览和打印的报告 PDF；
- `SHA256SUMS.txt`：交付文件校验值。

## 演示运行

1. 确认电脑已安装 Java 17 或更高版本；
2. 在项目根目录双击 `run.bat`；
3. 浏览器打开 <http://127.0.0.1:4173>；
4. 建议按“概览 → 新增交易 → 预算 → 报表 → 导出数据”的顺序演示；
5. 演示结束后关闭命令行窗口即可停止程序。

## 测试命令

```powershell
npm run validate
npm run test:browser
mvn -o clean package
```

所有财务数据只保存在当前浏览器的 `localStorage` 中。首次进入自动加载演示数据；如需恢复干净环境，可点击侧栏底部“清除全部数据”。
